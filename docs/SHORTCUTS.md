# Keyboard shortcuts

MyTerm exposes its shortcuts through native macOS menus. The core pane and navigation keys follow cmux, with <kbd>⇧⌘N</kbd> intentionally used for a new workspace as requested.

## Workspaces

| Action | Shortcut |
| --- | --- |
| New workspace | <kbd>⇧⌘N</kbd> |
| New folder | <kbd>⌃⌘G</kbd> |
| Rename workspace | <kbd>⇧⌘R</kbd> |
| Close workspace | <kbd>⇧⌘W</kbd> |
| Previous / next workspace | <kbd>⌃⌘[</kbd> / <kbd>⌃⌘]</kbd> |
| Select workspace 1–9 | <kbd>⌘1</kbd> … <kbd>⌘9</kbd> |
| Toggle sidebar | <kbd>⌘B</kbd> |

## Tabs

| Action | Shortcut |
| --- | --- |
| New terminal tab | <kbd>⌘T</kbd> |
| New browser tab | <kbd>⇧⌘L</kbd> |
| Previous / next tab | <kbd>⇧⌘[</kbd> / <kbd>⇧⌘]</kbd> |
| Select tab 1–9 | <kbd>⌃1</kbd> … <kbd>⌃9</kbd> |

## Terminal panes

| Action | Shortcut |
| --- | --- |
| Split right | <kbd>⌘D</kbd> |
| Split below | <kbd>⇧⌘D</kbd> |
| Close focused pane or tab | <kbd>⌘W</kbd> |
| Focus pane left / right | <kbd>⌥⌘←</kbd> / <kbd>⌥⌘→</kbd> |
| Focus pane up / down | <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> |

Folder colors, pinning, moving, renaming, and closing are also available from each folder or workspace context menu.
