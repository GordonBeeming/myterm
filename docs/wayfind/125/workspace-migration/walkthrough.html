Review points
  • Damaged or lossy sources stop automatic migration and retain the original. A repair report is evidence to review, never proof of a complete migration.
  • An existing account layout requires an explicit additional-import choice. First account enrollment's already agreed additive join remains a separate workflow.
  • Same-name workspaces remain distinct. A true identity collision stops; the candidate never regenerates an identity to hide it.
  • The complete candidate, local preferences and retry receipt commit together in one disposable snapshot. Production must compose these boundaries with the chosen replicated-layout and trust protocols.
