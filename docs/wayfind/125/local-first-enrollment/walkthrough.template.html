    Where this evidence stops
    The approval issuer is a trusted private-pipe fixture. The experiment uses real signatures, but it does not implement the approval ceremony or encrypted directory-key delivery. Content records preserve identities; they are not a complete workspace tree.
    Named process exits and blocked filesystem paths exercise specific recovery points. An uncertain post-rename commit stops the writer; actual sync errors, power loss and disk-full remain untested. Authority restart is covered; local runtime restart and durable endpoint keys are not.
    MyTerm Settings, actual workspace migration, relay traffic, multi-Mac use and iPhone/iPad acceptance remain open. Deletion here is an admission flag or content tombstone, without erasure or process cleanup. Restoring an old backup could restore revoked membership. Integrated process safety remains unproven.
