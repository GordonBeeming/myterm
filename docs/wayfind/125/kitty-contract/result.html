This is an unwindowed native NSView experiment with explicit coherent 1× font/image geometry. It is not live-window, Retina, iPhone/iPad, Linux/Windows, multi-Mac or production acceptance.

Experimental limits include 1 MiB checkpoint bytes, forty normal history lines, 32 cache images, 1,024 placements, 128 relative placements and 2 MiB aggregate relative raster cost. Anonymous image identity, animation and leased formats remain unsupported in this experiment.

Production terminal integration, the native raster-width investigation and other platform/alternate-buffer acceptance remain required. Production must paint from the retained native request and original pixels, rather than treating Rust's logical cell texture grid as a final pixel raster.
