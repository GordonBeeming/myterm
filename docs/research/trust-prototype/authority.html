    What the candidate assumes

    One honest, non-equivocating authority keeps its current key and journal. There is no automatic failover, no consensus and no safe unilateral replacement after permanent loss. Removing that server is blocked until an ordered authority transfer exists; transfer is not implemented.

    Agreed availability: no separate replacement/quorum mechanism is required. Removals wait when the ordering server is unavailable; another server is not promoted automatically. Server-backed work requires a reachable server, including the local server on Mac.
