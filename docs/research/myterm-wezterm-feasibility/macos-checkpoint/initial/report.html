MYTERM / NATIVE macOS ARM64 / THROWAWAY PROTOTYPE

Bounded state transfer works for part of the terminal contract

The custom Rust exporter restores actual SwiftTerm checkpoints. Three continuation differences and unsupported graphics/keyboard state still prevent acceptance.

Transferred state

Normal history and alternate buffer cells, hidden columns, widths, styles, saved cursor, current cursor, pending wrap, selected modes, margins, tabs, title and closed hyperlinks. Only an unfinished UTF-8/CSI/OSC token is retained as raw bytes.

Completed output, queries and session history are never replayed into the client.

Explicit limits

1 MiB encoded checkpoint, 16 KiB unfinished token, 1,000 columns/rows, 40 normal history lines, 100,000 imported cells and an exporter cell budget. These are experimental caps.

Graphics cells, pending DCS/APC, Kitty state, keyboard stacks and named extended states return errors. The exporter is not a complete validator of every possible terminal feature.

Captured native results

“Passed” means every captured continuation event matched the uninterrupted SwiftTerm client on the measured projection and selected native checkpoint fields. It does not mean complete terminal fidelity.

What the experiment establishes

Fresh native client instances import bounded state produced by the pinned Rust terminal core. A separate native producer and client pass the ordered pipe handoff workload. All 17 retained engine projections remain unchanged by the exporter instrumentation.

Native commands run on macOS ARM64. The Rust core carries the prior compatibility patch and checkpoint instrumentation; SwiftTerm carries the prior DCS correction plus this experimental importer. Production sources under Vendor/SwiftTerm are untouched.

What remains open

Graphics, keyboard stacks, broad parser/charset/palette behavior, complete hidden-state equivalence, epoch/generation resets, authenticated network transport, real PTYs, writer/viewer control, slow-reader recovery, pixel fidelity and long-running resource budgets. Independent review is recorded separately; this page does not imply review approval.

Selected checkpoint comparisons normalize default color variants, unused blank alternate storage and trailing blank allocation beyond the visible width. Meaningful hidden cells and hyperlink payloads remain compared. Unfinished parser behavior is tested by continuation, not by equating parser enum values across engines.

Import timings are single local Debug observations including JSON conversion and native checkpoint import. They are not release budgets or network latency measurements. The steady-output experiment bounds checkpoint size for its workload; it does not bound the engine’s total memory.

Validate Rust terminal state and SwiftTerm reconnect fidelity remains open. No release, deployment or source-control publication was performed.
