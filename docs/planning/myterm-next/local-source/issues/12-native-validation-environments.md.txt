## Question

Establish where the candidate server can actually be built and executed on native macOS, Linux and Windows. Inventory existing local tools, virtual machines and CI runner access before requesting new resources. Record OS, CPU, toolchain, PTY/ConPTY availability and exact commands for bounded experiments. Cross-compilation and WSL do not substitute for native Windows execution. Do not provision paid resources, deploy shared infrastructure or capture GUI focus without the authorization required for that action. Resolve when an actual accessible route to native validation is established, or leave the ticket open with a precise access requirement.
