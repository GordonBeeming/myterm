## Question

Which native runtime and component boundaries should own workspace persistence, terminal process lifetime, terminal screen/scrollback state, browser proxying and client connections? Decide the server contract, local startup defaults and process lifetime across UI quit, server restart and upgrade, with equivalent behavior on macOS, Linux and native Windows. Evaluate against the portability evidence and chosen trust model. Preserve phone access without any Mac UI process. This decision must make the first implementation workstreams concrete.
